# 🌐 Netbook - Social Network Landing Page

## 📖 Overview

Netbook is a modern and responsive social network landing page built using HTML and CSS. The project showcases a clean user interface designed for an online community platform where users can connect, join groups, share ideas, and interact with others.

## ✨ Features

* Responsive and modern design
* Attractive hero section with call-to-action buttons
* About Us section introducing the platform
* Community Features section
* Achievements and statistics section
* Team members showcase
* Latest News / Blog section
* Mobile app promotion (CTA) section
* Structured footer with navigation links and newsletter subscription

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* Responsive Design Principles

## 🎯 Purpose

This project was created to practice front-end web development skills, including page layout, CSS styling, responsive design, and organizing a multi-section landing page. It demonstrates the ability to recreate a professional UI design using only HTML and CSS.
